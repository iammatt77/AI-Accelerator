**Dátum:** 2026-07-14 · **Branch:** `dev` · **Forrás-igazság:** `AICON_Handoff_Master_READABLE.html` (kizárólagos vizuális referencia)

## Összefoglaló

A teljes rendszer UI-ja átállt a Handoff Master lapos-tömör vizuális modelljére: tömör fehér felületek (#FFFFFF) lapos #ECEEF4 háttéren, EGY árnyék-token, 4–6px sarok-rádiusz, glassmorphism/backdrop-blur teljesen kivezetve. Mind az öt képernyő (Dashboard, Cockpit, Phase Workspace, Document Repository, Document Editor v3) + a kétszintű sidebar a Master szerint épült újra, minden állapottal (1a/1b). A régi és az új NEM keveredik: nincs több üveg-felület a kódbázisban.

**KEMÉNY KORLÁT betartva:** csak prezentációs változás. Fázis-állapotgép, kapu-logika, E1-lánc (AI javasol → ember erősít meg), dokumentum-státuszlánc (Draft → In review → Approved, üres kötelező mezőnél approve-blokk), entitás-lánc, generálás/citáció/verziózás, összes server action és adatmodell változatlan. Minden meglévő funkció elérhető maradt.

## Funkció-megőrzés (szúrópróba a lokális stacken)

- E1-akciók (Megerősít / Szerkeszt / Elvet) a workspace-en és az editor-accordionban a MEGLÉVŐ server actionökkel renderelnek.
- Approve kemény blokk: in_review + üres kötelező mező → letiltott gomb a hiány számával (a szerveroldali őr változatlan).
- md-export, verziótörténet, „Új verzió", kapu-zárás őr, heatmap fókusz-mód — mind elérhető az új UI-ból.
- Megjegyzés: a lokális teszt-DB-ben a Panaszkezelés projektnél P1 ÉS P2 egyszerre `in_progress` (korábbi kapu-walkthrough maradványa) — a tár emiatt két AKTÍV szekciót mutat; ez adat-állapot, nem UI-hiba: a nézet hűen tükrözi az állapotgép tábláját.

1. **Inbox** — maradt link-gyűjtő placeholder; a Master értesítés-központtá bővítené (adat + akciómodell-változás).
2. **⌘K keresés** — csak vizuálisan renderelt keresőmező a dashboarden; a keresés-funkció külön csomag.
3. **„See a sample project" gomb** (Dashboard 1b) — kihagyva: minta-projekt seedelő server actiont igényelne.
4. **Bundle-PDF export** (Repository export-csempe) — a meglévő egy-dokumentumos md-exportra mutat; a több-dokumentumos PDF-köteg új funkció.
5. **Per-mező „✦ Javaslat (te erősíted meg)"** (Editor v3, §06) — új server actiont + LLM-hívást igényelne; helyette a meglévő „Kézi kitöltés" + E1-akciók.
6. **Strukturált mező-tömbök / „markdown-fal törölve"** (§06/§07 adatmodell-vázlat) — adatmodell-változás; a body megmarad CSUKOTT „Body (markdown)" accordion-sorként (funkció nem vész el), az előnézetben Bevezetőként renderel.

8. **Review-ra küldés** — mindig engedélyezett maradt (letiltása funkció-változás lenne); a készültséget az összefoglaló sáv kommunikálja.
