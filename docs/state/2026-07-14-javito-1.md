## 1. Before → After — Phase Workspace (AICON_3), pontonként

1. **Egy elrendezés, nem három** — ✅ **KÉSZ.** A zone-*tabs* helyett
   **zone-flow-strip**: négy stat-kártya (`ZoneFlowStrip`) `›` nyíl-
   összekötőkkel, a kiválasztott zóna kiemelve („ITT"). Nincs variáns-választó.
   A fül→panel mechanizmus megmarad (kártya-kattintás vált panelt), így minden
   funkció elérhető.
2. **A függő pain in-place bővül** (idézet + forrás + confirm/edit/dismiss egy
   képernyőn) — ✅ **KÉSZ.** `DrillRow` + beágyazott `PainPointProposalCard`:
   a fejlécen inline Megerősít/Elvet, kinyitva az idézet, a forrás [n] és a
   Szerkeszt — nincs elmosódott üveg-oldalpanel.
3. **A Gate-kártya megnevezi a nyílt kritériumot** — ✅ **KÉSZ.** A flow-strip
   Gate-kártyája: „Nyílt: {kritérium}" (nem csupasz „1/2").
4. **Precíz, forrás-ID-s citáció** — ✅ **KÉSZ (a valós sémával).** A pain-
   bővítés forrás-idézet-kártyát + [n]-citációt mutat; a konkrét szám a seed-
   adatból jön. **Eltérés:** a rendszer citáció-ID-i numerikusak (`[1] [2]`),
   nem `F`-prefixesek — a valós citáció-generálás/parse sémát megtartottuk (az
   `F`-prefix csak a terv-copy jelölése).
5. **„AI SUGGESTION — NEEDS YOUR CONFIRM" felirat-szintű címke** — ✅ **KÉSZ.**
   `entities.aiSuggestionLabel` (HU: „AI-JAVASLAT — MEGERŐSÍTÉSRE VÁR"),
   `bg-tint-action` + `text-action-deep`, a beágyazott javaslaton — külön a
   státusz-pilltől.
6. **Refined empty state (1b)** — ✅ **KÉSZ.** Input = dashed-lila „Add meg az
   első nyersanyagot" prompt a valós bemenet-felvétellel; a downstream zónák
   szürkén, a saját unlock-feltételükkel; alul „Következő legjobb lépés" sáv.
   **Eltérés:** a terv „Paste transcript / Upload file" gombjai helyett a
   rendszer tényleges add-input űrlapja (funkcionális megfelelő).

## 2. Before → After — Document Editor (AICON_5), pontonként

1. **Blokkoló-sáv + mezőtérkép-sín ugró-linkekkel, TÖMÖR lapok** — ✅ **KÉSZ.**
   A blokkoló-sáv + mezőtérkép (borostyán ☐ az üres kötelezőn) megvolt; most a
   panelek `glass-tile`→**tömör** (`bg-surface` / `bg-neutral-50` + keret).
2. **„Draft a suggestion (you confirm)" (nem auto-fill)** — ⚠️ **FLAG (l. 4.
   szakasz).** A per-mező AI-javaslat ÚJ server actiont + LLM-hívást igényel —
   a csomag szabálya szerint jelezve, nem építve csendben. Az üres kötelező mező
   a v2 szerint **szaggatott borostyán doboz** (csak draftban), a „Write
   manually" a meglévő szerkesztésre köt.
3. **Források-panel „N sources · M citations" + dátum/idézet** — ✅ **KÉSZ.**
   `editor.sourcesCountLabel` = „{sources} forrás · {citations} citáció a
   draftban" (a citáció-szám a body valós `[n]`-jeiből); forrásonként
   dátumbélyeg + idézet-kivonat; a citált/aktív forrás kiemelve (kék `pivot`

4. **Státuszlánc irányított folyam, az aktív dominál** — ✅ **KÉSZ.** `StatusFlow`

5. **Tömör lila elsődleges CTA-k** — ✅ **KÉSZ.** Export PDF + „Ugrás a kapuhoz"

6. **Approved / read-only nézet** — ✅ **KÉSZ.** Zöld banner („…a kapu zárásra
   kész" + tömör lila „Ugrás a kapuhoz"), solid-zöld Approved pill, VERZIÓK-sín
   „Bármely két verzió összevethető · a diff overlayben nyílik" sorral.

## 3. Oldal-melletti illesztés — konkrét hex/token-értékek

A `tokens.css`/`@theme` mappingen át (a fájl a mérvadó, ezekhez igazítva):
- **Pozitív/„Confirmed" pill:** `bg-done` = `--status-done` = **#3E9E6E**,
  fehér szöveg, `rounded-pill`, ikon+szöveg (törvény 4). A v2 `#3E9E6E`-jével
  azonos.
- **Aktív in_review pill:** `bg-gate` = `--status-gate` = **#B4801E**, fehér.
- **Lila CTA:** `bg-action` = `--action-primary` = **#8458B3**; a mélyebb
  `--action-deep` = **#7A4FB0** a címkéken/aktív-szövegen (a v2 kéttónusú lila).
- **AI SUGGESTION címke:** `bg-tint-action` (rgba(132,88,179,0.12)) +
  `text-action-deep` (#7A4FB0).
- **Hőtérkép — kitöltött csempe = shortlisten:** `bg-action` **#8458B3**;
  outline (nem shortlist): `border-neutral-450` **#b4b8c6** + `bg-surface`.
- **Kockázat-betű tag:** L = `bg-tint-done/text-done`, M = `bg-tint-gate/
  text-gate`, H = `bg-danger/15 text-danger` (**#c0455a**).
- **Háttér:** `--bg-app` **#EAECF3** (nem írtuk felül); tömör lapok
  `--surface-solid` #FFFFFF + `bg-neutral-50` **#fbfbfd** a síneken.

**Kitöltés vs. halvány (a fő panasz):** a lezárt/pozitív jelvények és az aktív
státusz-csomópont most **tömör** (nem halvány szöveg), a fő CTA-k **tömör lila**
— pontosan a v2 szerint.

## 4. „Ehhez funkció-módosítás kellene" (FLAG — NEM építve csendben)

- **Per-mező „Draft a suggestion (you confirm)"** (v2 editor 1a lila gomb):
  a rendszer kivonatolása az EGÉSZ dokumentumot tölti (workbench-ből); egyetlen
  mező AI-javaslata **új server action + LLM-hívás + per-mező parse**. Ez
  backend-bővülés, nem megjelenítés — jelezve. A mező-doboz a v2 szerint néz ki,
  a „Write manually" (meglévő `editFieldAction`) elérhető. Döntést kér: külön
  kis backend-lépésként megépítsük, vagy a doboz maradjon „Write manually"-only.

## 5. Tudatos eltérések a v2-től (indokolt)

- **Kvadráns-címkék:** a MEGLÉVŐ i18n-kulcsok szövege marad (Strategic bet /
  Kerülendő / Opportunista), tartalmilag = BIG BETS / DEPRIORITISE / FILL-INS
  (a csomag: „a meglévő i18n-kulcsokból dolgozz").
- **Governance-megtartás a hőtérképen:** a v2 a kockázatot csak a kitöltött
  pontokon mutatja; nálunk a **kockázat-betű MINDEN ponton** látszik, és a #7b
  **AI Act-figyelmeztetés (piros ▲) megmarad** — a törvény 4 / AI Act miatt (a
  megerősítéskor jóváhagyott, nem elhagyható governance-jel).
- **StatusFlow tömör kontraszt:** a v2 fehér-a-tömör-színen (≈3–3,5:1) az előző
  kör kontraszt-halványítását felülírja; a locked spec a hierarchiát priorizálja
  (a felirat bold, kis UI-chrome).
- **App-shell oldalsáv** (~224px, bal): globális nav — nem e csomag scope-ja
  (mobil-összecsukás külön, l. előző jelentés).
